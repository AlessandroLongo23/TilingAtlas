# Concepts

The tilings theory itself, separate from how STS encodes it.

Read in this order:

1. [[classification]] — his six levels (regular → multibrid), the map of the territory.
2. [[k-uniform-tilings]] — the Euclidean enumeration and its counts.
3. [[hyperbolic-tilings]] — what changes without similarity: per-edge-length lists, parametric
   families, the non-triangular m/k table, morphs, apeirogons.
4. [[hybrid-identities]] — edge functions, mixing rules, apeirogonal arithmetic; the deep end.

One-liners in the [[glossary]]; unanswered things in [[open-questions]].
