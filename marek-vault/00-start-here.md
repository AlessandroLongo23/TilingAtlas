# Marek vault — start here

Everything I'm learning from Marek Čtrnáct about tilings: the raw Discord conversation, plus the
curated notes I build on top of it. Open this folder as a vault in Obsidian.

## Two layers

- **Archive** (`archive/`, local only) — the Discord DM, one note per day, generated by the importer.
  Not in git. Regenerate it any time from a fresh export.
- **Knowledge** (`knowledge/`, in git) — my own distilled notes: notation, the engine, concepts,
  annotated scripts. These are what I actually write and keep. They link back to the archive so I can
  always see what Marek actually said.

## Folders

- `knowledge/notation/` — Conway symbols, vertex configurations, palette JSON, the "čtrnáct" naming.
- `knowledge/algorithm/` — the combinatorial engine: dual-search, half-edge gluing, canonical form,
  the develop stage.
- `knowledge/concepts/` — the tilings theory itself (k-uniform, vertex configs, duals).
- `knowledge/scripts/` — one annotated note per script he sends, linked to the source message and file.
- `knowledge/glossary.md` — quick term → one-line definition → link to the deep note.
- `questions/` — what I still don't understand and want to ask him.
- `templates/` — note templates (see below).
- `archive/`, `attachments/`, `_raw/` — generated / raw, all gitignored.

## How to get the chat in here

See [[how-to-export]]. Short version: run DiscordChatExporter locally into `_raw/`, then
`node scripts/import-marek-chat.mjs` from the repo root.

## Citing a source message

Every imported message carries a block anchor `^msg-<id>`. To pull the exact message into a knowledge
note, embed it:

```
![[archive/2026-07-14#^msg-1002]]
```

To embed a whole message with its heading, link the heading instead:

```
![[archive/2026-07-14#12:16:00 — Marek]]
```

Links to files elsewhere in the repo (the actual engine code) are plain relative links, because
Obsidian wikilinks only resolve inside this vault. Example: the engine lives at
[../tools/ctrnact-oracle/README.md](../tools/ctrnact-oracle/README.md).

## Templates

`templates/` holds three: `concept`, `script`, `daily`. Point Obsidian's core Templates plugin at the
`templates` folder (Settings → Core plugins → Templates → Template folder location) to insert them.

## A note on privacy

The raw conversation stays on my machine (gitignored). Only my curated notes get committed. Marek
knows I'm keeping these notes. Don't paste his raw messages verbatim into the committed knowledge
layer — summarize, and cite the archive anchor for the exact wording.
